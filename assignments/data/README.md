## Datasets

### Network Flow
The following datasets used in `final-project.ipynb` are the airport data from the ["Network Analysis Made Simple" repository](https://github.com/ericmjl/Network-Analysis-Made-Simple/tree/master/data)].
- `GlobalAirportDatabase.txt`: Global airport database which includes IATA codes, longitude, latitudes, and etc.
- `passengers.csv`: Annual passenger statistics for each airline routes.
